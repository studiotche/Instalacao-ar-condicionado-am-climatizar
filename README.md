# Site do Nutricionista Esportivo Pedro Zvir

Site estatico, responsivo e otimizado para SEO local, com foco em conversao pelo WhatsApp.

## Desenvolvimento

Comandos: npm install, npm run dev e npm run build.

O site apresenta os dados profissionais, endereco, horarios, servicos, depoimentos e links oficiais do Pedro Zvir. Antes da publicacao definitiva, valide o JSON-LD e envie o sitemap no Google Search Console.
